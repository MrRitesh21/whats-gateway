WAflow (WhatsGateway) Architecture

Multi‑Device WhatsApp Management Gateway – Next.js 16, Prisma, Baileys, Docker

Tech Stack

  • • Next.js 16 (App Router)
  • • TypeScript
  • • Prisma ORM + PostgreSQL
  • • @whiskeysockets/baileys
  • • NextAuth.js
  • • Docker (optional)

Key Features

  • • Multi‑device WhatsApp sessions
  • • REST API & Webhooks
  • • Broadcast & Scheduler
  • • License validation (WebotApp Lab)
  • • Admin dashboard & RBAC
  • • Swagger API docs

Deployment

  • • Vercel (serverless) or Docker
  • • Environment: .env (APP_NAME, DATABASE_URL, etc.)
  • • License check: SKIP_LICENSE_CHECK toggle
  • • Port: 3030 (dev) / configurable
  • • Health endpoint: /api/health
